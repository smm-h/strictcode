# Support matrix

Cells read `supported` (the extractors it needs exist and are tested), `planned` (designed, not
yet implemented), or `n/a` with the reason it is meaningless in that ecosystem.

The rule cells are computed by strictcode's Go code from each rule's requirements, the language
profiles, and per-rule overrides (see [capabilities and profiles](../capabilities-and-profiles/)),
and written into `schema/registry.json` by `strictcode registry dump`. This page only lays them
out, so it cannot disagree with the tool.
